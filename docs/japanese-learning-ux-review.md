# 日語學習 UX 稽核與改善

## 修改前稽核（2026-10-05）

範圍：共用 LyricsLearning、逐行學習解析與歌曲頁。未變更歌詞、歌曲事實、網址、資料模型。正式建置基準通過，共 423 個 HTML。瀏覽器檢查本機正式預覽的 Idol、夜に駆ける，375、390、430、768、1280、1440 px。各尺寸無水平溢出，初次使用四項輔助均關閉。Idol 首句高度約 212 px，390 px 學習區高度約 12,487 px；日文行高 50 px，控制區約 129 px。console 未見警告或錯誤。

線上 https://cervellomyrtenaster.github.io/yoasobi-guide/songs/idol/ 取得的渲染版本未包含逐行學習控制；本次介面驗證以本機 production build 為準，不將尚未部署的修改稱為線上成果。

| 優先級 | 發現 | 處理範圍 |
| --- | --- | --- |
| P1 | 初次使用全關，初學者無讀音、翻譯；切換歌曲重設 | 振假名及中文預設開啟；防禦式儲存共用偏好 |
| P1 | 行號獨占一列、50 px 日文行高與多重預設段落間距，長篇捲動疲勞 | 行號置於側邊，調整 ruby 與段落節奏，保留原文優先 |
| P1 | 控制區捲離後需返回頂部才能切換 | 僅在學習區內固定精簡控制列，確認錨點不遮擋 |
| P2 | 每次勾選逐一查詢並修改所有輔助行 | 改用父層狀態屬性及 CSS 顯示；只初始化一次 details |
| P2 | 進階者需取消四項才能純日文 | 一鍵只讀日文；仍保留四項獨立勾選 |
| P2 | 手機 MV 與閱讀區距離較遠 | 保留頁面架構，報告限制，不增設重複播放器或虛構同步 |
| P3 | 沒有歌曲內段落、逐句翻譯點閱及時間同步 | 不自動新增；現有資料無時間戳 |

### 四類學習者

- 零基礎：需要讀音、羅馬拼音與翻譯；預設振假名、中文，可自行加入拼音，避免五層全開。
- 初級：可持續使用振假名與中文，跨歌曲記住不依賴拼音的選擇。
- 中級：隨時隱藏翻譯與讀音；縮小純日文行高，但 ruby 開啟時留足空間。
- 高級：一鍵純日文；單字文法仍採原生折疊，不強迫閱讀筆記。

### Keep / Improve / Avoid

保留：紙色底、紅色操作色、語意 ruby、原生 checkbox、逐句穩定 ID、單字文法雙向錨點、原生 details 無 JS 備援、建置時資料處理、點擊才載入 YouTube。

改善：預設值、偏好、行距與行號、長篇控制操作、父層狀態切換。

避免：逐句卡片、反覆語言標籤、新框架、內容改寫、多播放器、虛構同步、四套分離介面。

### 修改與原因

| 問題 | 改善 | 檔案 |
| --- | --- | --- |
| 全關預設、不會記住選擇 | 振假名及中文預設開啟，其餘關閉。共用 `yoasobi-guide:learning:v1`；JSON 僅接受布林，儲存不可用不阻止閱讀 | `LyricsLearning.astro`、`learning-preferences.ts` |
| 逐句留白與日文行高過大 | 側邊 44 px 行號連結；日文行高 1.85，有 ruby 時留空間；純日文 1.65。移除逐句分隔線，維持紙色與原文主體 | `LyricsLearning.astro` |
| 長篇找不到控制、調整後迷失句子 | 控制僅於學習區內固定，手機兩欄 105 px、桌面一列 61 px；切換保留首個完整可見句位置，無平滑捲動動畫 | `LyricsLearning.astro` |
| 進階者需逐項取消 | 一鍵「只讀日文」，選擇亦跨歌曲保存 | `LyricsLearning.astro` |
| 每次切換遍歷修改所有輔助行 | 只變更父層四個狀態，CSS 決定可見性；一次性初始化 details，閱讀錨點只查可見行位置 | `LyricsLearning.astro` |
| 壞資料、儲存拒絕可能中斷功能 | 新增 3 項測試覆蓋無效 JSON／型別、完整保存、拒絕存取 | `learning-preferences.test.ts` |

沒有新增套件、變更 schema、重寫歌詞或移動歌曲頁區塊。未增加 layer-label、逐句卡片、播放器或時間同步。原生 checkbox 不需要額外 aria-pressed；group legend 對輔助技術仍可見，鍵盤 focus 為 3 px 實線。

- `pnpm run check`：78 個檔案，0 errors／warnings／hints。
- `pnpm run test`：37 項全部通過（原 34 項、新增 3 項）。
- `pnpm run build`：423 頁，static，通過。基準與完成後皆無建置警告。
- `pnpm run test:static`：25,111 個本地引用、13,824 個錨點，0 未解析；12 個外部 JS 檔案共 14,908 bytes。此數字不包含 HTML 內嵌腳本，不宣稱 JS 總量減少。
- `node --import tsx .qa/verify-lyrics-build.ts`：38 份、1,600 句、2,167 單字筆記、556 文法筆記，原文與全部輔助文字保留。
- Idol 與夜に駆ける，各於 390／768／1440 px 測試指定五種組合，共 30 組；全部無水平溢出、各層顯示符合選擇。另視覺檢查 375／430／1280 px。
- 原文 `lang="ja"`、拼音 `ja-Latn`、中文 `zh-Hant`；ruby 保留語意，圖片畫面未見 ruby 碰撞。
- 跨歌曲、重新整理、全開與純日文偏好保留均通過。
- 長篇鍵盤切換時可見句的位置保留。自動化 locator click 會先自行捲動再觸發事件，不能以該前置捲動當成實際閱讀回歸；使用已聚焦控制的 Space 檢查，記錄同句切換前後 top 均為 284.84 px。
- 第一句單字連結可展開單字資料，回程連結返回 L001。390 px 的筆記 top 為 112.42 px、控制底端 105 px，未遮擋。
- 返回頁頂後 scrollY 為 0，按鈕隱藏、焦點回品牌連結。控制在上方、返回頂端按鈕在下方，兩者未重疊。
- 同模式比較：390 px 純日文首句 212 → 113 px；全部筆記折疊的學習區 12,487 → 7,147 px。新的預設振假名＋中文會較純日文長，不以不同組合計算減幅。
- Browser console 未見 error／warning。DOM 及靜態輸出驗證本地資源，沒有完整 network HAR；不宣稱所有第三方網路請求均成功。
- 點擊 Idol MV 後成功建立具標題的 16:9 youtube-nocookie iframe，但內嵌播放器實際顯示「無法播放這部影片」。保留既有「在 YouTube 開啟」入口，未更改影片 ID、限制設定或宣稱播放成功。
- 無 JS 原生 details 備援由程式碼檢查確認；未用停用 JS 的瀏覽器情境測試。

本次工具執行曾誤把 `--ignore-lock` 傳給 static 檢查作為目錄，另嘗試 pnpm 不支援的全域同名參數；修正為上述正式命令後均通過。這是驗證指令錯誤，未更動產品或依賴。
