# 五種使用者情境：內容與閱讀體驗檢視

後續狀態：使用者已完成發布；公開〈アイドル〉逐行學習已抽查確認。依本報告實作的新改善與仍待查項目見 [改善紀錄](persona-improvements-2026-10-05.md)。以下保留原稽核當時的觀察。

檢視日期：2026-10-05。這是一輪實際瀏覽與編輯檢視，沒有改版、重建資料模型或新增未經查證的音樂史資料。

## 結論

目前最能滿足的是初學者：從動畫歌曲、五首入門、成員經歷到原作小說，已有連貫的探索路線。演唱會準備也能迅速給出五首優先曲目，但歌單樣本的年代與場景分布仍限制了推薦的即時性。

中階使用者能找到比唱片目錄更多的故事、製作資料與作品關係，卻會發現不同歌曲的深度不一致。老玩家目前最難被滿足：網站的資料整理有用，但跨時期評論、輿論脈絡、演出變化與經查證的軼事仍不足。

本機正式建置的日語學習已能逐行閱讀並查單字、文法；公開版抽查的〈アイドル〉仍只有 marumaru 外部入口，沒有逐行閱讀控制。因此以下評分針對本機目前的正式建置，不能直接視為公開版已提供全部功能。

## 方法與範圍

- 使用 Astro 正式建置與預覽：`http://127.0.0.1:4324/yoasobi-guide/`，不是只閱讀原始碼。
- 五個情境各開獨立分頁，從首頁重新找入口。演唱會與入門路線起始皆顯示 0／5；沒有因前一個情境找到入口，就直接替下一個情境跳到目的頁。
- 分頁共用同一瀏覽器來源的偏好，沒有建立五個隔離的瀏覽器設定檔，也沒有清除使用者的 localStorage。日語顯示偏好另以實際控制切換驗證，最後恢復振假名／中文開、全假名／羅馬拼音關。
- 實際量測到 390px 手機、1280px 與 1440px 桌面寬度。曾要求 768px 視窗，但該分頁實測仍為 1440px，故不列為成功的平板驗證。
- 這是專家模擬，不是招募真人的可用性測試；點擊數取自實際路線，沒有宣稱已用真人計時證明一分鐘成功率。
- 公開版另從首頁、入門入口走到〈アイドル〉，確認目前可開啟，以及逐行學習與本機版的差異。
- MV 以實際按鈕載入播放器驗證；〈好きだ〉在本次內建瀏覽器顯示 YouTube「無法播放這部影片」，因此不宣稱播放成功。網站的外部 YouTube 備援連結仍可見。沒有把此結果直接判定為歌曲 ID 錯誤或所有瀏覽器皆無法播放。

## 1. 臨時抱佛腳者

**實際路線：**首頁 →「演唱會前，從這裡開始」→ 30 分鐘路線 →〈群青〉→ 返回原路線與歌曲位置。

|任務|結果|
|---|---|
|快速找該學的歌|首頁一次點擊就能看到〈夜に駆ける〉、〈群青〉、〈怪物〉、〈祝福〉、〈アイドル〉。結構上符合一分鐘內得到答案的目標。|
|理解優先原因|每首有推薦理由與已收錄演出的次數；前三首在專場樣本 10／10，〈祝福〉與〈アイドル〉為各自發行後樣本 9／9。這些是本站收錄樣本，不是全生涯統計。|
|選準備深度|有 30 分鐘、約兩小時、三天路線；不用先讀完整歷史。|
|歌曲與 MV|歌曲頁有點擊載入的官方影片與外部備援；播放成功受到本次測試環境限制。|
|回到進度|從〈群青〉返回 `/listen/concert-first-five/#song-gunjo`，沒有回到陌生的歌曲目錄；連續聆聽也保留來源。|
|近況是否影響推薦|有近期作品補充與選曲理由，但最新完整歌單樣本到 2025-11-30；音樂祭樣本都在 2023 年，無法支持 2026 年近期常演排行。|
|是否建立參加信心|能建立「我至少認得這五首」的信心；不足以保證熟悉特定即將參加場次的曲目。|

**已有且強：**首頁入口明顯、五首清單直接、時間路線清楚、返回位置可靠、樣本限制沒有藏起來。

**已有但淺：**30 分鐘路線的逐首練習多為辨認前奏／副歌，缺少每首不同的現場辨識重點。三天路線有安排，仍不是按即將參加的巡演整理的指南。

**難發現：**統計與比較頁能回答更多，但主路線讀者未必知道要再進去確認某個年代或場景。

**缺少：**近期且多樣的完整音樂祭歌單、2026 年已完成演出的來源與足夠樣本、按巡演整理的準備內容。

**摩擦：**「常演」最容易被誤讀成下一場保證；頁面須持續保留樣本時間與分母。不要為了讓新手安心而省略這些限制。

## 2. 初學者

**實際路線：**首頁 →「開始認識 YOASOBI」→ 動畫入口／五首聆聽 → 關於 YOASOBI → Ayase、ikura → 返回入門路線。

|任務|結果|
|---|---|
|知道組合與角色|能找到 Ayase 作詞作曲／製作、ikura 演唱的分工與小說改編概念。|
|知道怎麼開始|有成立與出道背景，成員頁有 VOCALOID、ぷらそにか及個人活動經歷；能分辨組合與個人活動。|
|從動畫歌開始|入門頁用熟悉歌曲接到更廣的作品，沒有只丟出完整目錄。|
|認識至少五首|「五首，五種故事入口」有順序與練習提示，起始進度 0／5。|
|看 MV 與現場|官方 MV、現場索引及部分歌曲現場片段都有入口；五首路線並非每首都附現場片段。|
|理解發展與下一步|年代導讀、作品、成員與深入聆聽能形成連續路線。|

**已有且強：**小說→音樂的概念、分工、動畫橋接、五首聆聽路線，都比單純按年份排列作品更適合新手。

**已有但淺：**部分練習提示仍可更貼近每首歌；歷史摘要可以知道發展階段，較少解釋相鄰階段之間的聲音與題材轉變。

**難發現：**深度研究、作品關係與現場索引分散於延伸連結。新手完成五首後，未必會自然接到一組明確的第二輪作品。

**缺少：**按「喜歡動畫／喜歡故事／喜歡現場」分類的第二輪聆聽推薦。這可沿用既有歌曲，無需新增另一套內容模型。

**摩擦：**關於頁原本仍說本站不刊載歌詞，與本機版學習功能矛盾；本輪已修正。不要把研究資料、榜單與來源說明全部提到新手的第一步。

**判斷：**完成此路線後，使用者有機會建立清楚的概念：兩位成員的分工、故事改編如何運作、動畫合作與其他作品的關係、接下來怎麼聽。這是目前最完整的情境。

**實際路線：**深入聆聽 →〈祝福〉→ 展開作品研究與成績 → 歌曲目錄搜尋不同時期作品 → 查看研究、MV、現場與作品歷程 → 返回保留查詢的目錄。

抽查早期〈夜に駆ける〉、動畫〈祝福〉、大熱門〈アイドル〉、後來收錄於 EP 的〈もしも命が描けたら〉、相對非主打熱門的〈ミスター〉。不是把後兩首稱為最初僅有專輯發行的作品。

|---|---|---|---:|---|
|夜に駆ける|可查|有創作者訪談、藍にいな MV 留白與製作資訊|4|有|

**已有且強：**來源、作者、EP 收錄、影片、作品歷程與相關作品能互相連接；搜尋後返回仍保留查詢。小說與合作用途的區分清楚。

**已有但淺：**多數頁的聲音分析仍是提問型聆聽引導；不一定有創作者對具體編曲、錄音或改編取捨的說明。獎項、提名與成績集中在少數作品。

**難發現：**訪談、製作職務與研究藏於可展開區塊；在不知道裡面有什麼之前，使用者可能只讀到一般介紹。本輪加了四個具體問題入口，讓既有有趣資料較容易被找到。

**缺少：**非熱門作品的成績與認證、提名／獲獎對象、具名評論、重要演出的原因與不同現場版本分析。

**摩擦：**成績元件曾連續重複相同的描述與來源範圍，本輪只在兩者文字完全相同時省去第二次顯示。資料與來源連結保留。

**判斷：**已比簡單 discography 有更多理解，但「每首都能深度研究」目前不成立。

## 4. 老玩家

**實際路線：**首頁 → 歷史搜尋〈ミスター〉→ 作品關係／深入聆聽 → 歌單統計 → 音樂祭篩選 → 兩場歌單比較。

|任務|結果|
|---|---|
|回顧完整年代|歷史可搜尋、分類；公開歷史紀錄 296 筆，另有 42 筆成績紀錄顯示於歷史視圖。9 筆候選歷史未公開，沒有混入已確認項目。|
|追歌曲跨發行與現場|歌曲歷程比僅搜尋總時間軸更合適；總時間軸搜尋歌名不一定包含所有演出關係。|
|比較演出|可比較同巡演連續兩日、海外／日本、音樂祭／巡演；預設 WANDARA 沖繩兩日顯示共同 17 首、左側獨有 1 首、右側獨有 0 首。|
|常演／少演曲|可看已收錄次數與零次歌曲，但零次只能稱為「本站樣本未列」，不能推定從未演唱。|
|版本與合作|作品頁與相關作品能找英文版、改編、Remix、合作及其他版本；79 筆歌曲記錄不是 79 首獨立日文原曲。|
|來源與有趣細節|可追原作、MV 職務、應援參與、刺繡製作等；需主動展開和串連。|
|評價、輿論、賞析|已有少數具名評論和本站聆聽筆記，尚未形成可對照的評論史或公共討論脈絡。|

**已有且強：**來源可追、日期精度與統計限制清楚、版本關係、演出對照及作品歷程，是相較影音平台有價值的整理。

**已有但淺：**演出資料可以比較選曲，但不足以追出整個生涯的歌單變化；賞析多為提示，未形成深入的音樂與敘事比較文章。

**難發現：**既有趣聞沒有清楚主題入口；同一歌的資料散在歌頁、原作、發行、歷史、現場與成績，不一定有完整的閱讀終點。

**缺少：**不同年代與立場的具名評論、當時爭議或公共討論的發生／回應／後續、經查證的製作軼事、初演與編曲變化、巡演代表性與罕見曲的可核對研究。

**摩擦：**總時間軸很長；逐筆事實多，但「為什麼這個變化值得注意」的綜合說明少。用籠統的「廣受好評」或未具名網友反應補上，反而降低價值。

**判斷：**有資料整理價值，但尚不足以讓已熟悉基本事實的人長期反覆回訪。這是目前最弱的情境。

## 5. 日文學習者

**實際路線：**首頁頁尾「唱歌學日語」→ 可學習作品 →〈好きだ〉→ 逐行閱讀 → 第一句單字／文法 → 單字筆記 → 返回原句／學習入口。

|任務|結果|
|---|---|
|逐行讀音與理解|本機版 38 份學習檔，共 1,600 行；日文固定可見，振假名、全假名、羅馬拼音、中文可分別開關。|
|選閱讀深度|有「只讀日文」；振假名／中文預設顯示，沒有一開始展示所有層次。|
|查單字、文法|逐句展開與筆記有雙向連結；共 2,167 筆單字條目、556 筆文法條目，數量不是去重後的詞彙數。|
|跟唱|可聽官方影片、逐段練習；沒有時間軸同步，也沒有虛構歌詞時間。|
|跨歌曲偏好|羅馬拼音的選擇在下一首仍保留；手機控制與內文沒有觀察到頁面水平溢出。|
|公開版是否相同|抽查公開〈アイドル〉只有外部 marumaru 入口，沒有本機版的逐行學習與勾選控制。|

**已有且強：**日文優先、按需顯示輔助、逐句筆記、回到原句、保留偏好，適合從閱讀到減少拼音依賴。

**已有但淺：**有知識條目，較少要求使用者自己回想、換句說或分段跟唱的練習；不能由條目數量推斷教學品質。

**難發現：**首頁入口位於頁尾；學習頁先列 38 首，再出現方法與練習安排，手機使用者可能還沒讀到方法就已選歌。

**缺少：**明確的短篇首次練習示範、按日文程度選歌／選段、小型複習任務，以及長期的日語內容人工審校。

**摩擦：**MV 與長篇學習內容距離大，手機往返耗時。部分單字條目把完整詞條與來源中實際切出的表面形／讀音放在一起，例如「居る」與「居（い）」；需要教學說明以免初學者誤認詞形。譯文也可能依跨句語意安排，不能機械地要求每行與日文單行一一對等。本輪沒有修改使用者提供的詞、文法或翻譯內容。

## 本輪已做的文字改善
